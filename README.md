# Genx Studio

نظام إدارة محفظة حسابات Genx على انستغرام وتيك توك وفيسبوك. تشتغل عليه من داخل Claude Code كشريك استراتيجي: أنت تقرر، والـ agent يخطط ويكتب ويجهّز الإنتاج والنشر ويحلل ويتعلم. **كل حساب مشروع معزول.**

## الحسابات (المرحلة التجريبية)
| الحساب | النوع | الفكرة A | الفكرة B |
| --- | --- | --- | --- |
| `tob-w-dahab` توب ودهب | مجتمع: جمال وذهب وموضة | عرض الذهب والإكسسوارات | تنسيق إطلالات بأسعار في المتناول |
| `kisra-w-afia` كسرة وعافية | مجتمع: أكل وصحة | وصفات سريعة بلمسة سودانية | تبسيط التغذية وتصحيح المعتقدات |
| `hammoudi` حمّودي | شخصية كرتونية | مواقف عائلية فكاهية (كوميكس) | محتوى للأطفال والأسرة |

الأسماء مؤقتة.

## الأسبوع العادي
```
/plan-week tob-w-dahab      ← خطة للموافقة
/write-content tob-w-dahab  ← المنشورات + prompts الإنتاج
/review                     ← تعتمد / تعدّل / ترفض (فردي أو جماعي)
/produce tob-w-dahab        ← Magnific: آلي أو حزمة prompts
/publish tob-w-dahab        ← حزمة نشر وتسجيل الروابط
/weekly-report tob-w-dahab  ← الأرقام والتحليل وتحديث playbook
/portfolio                  ← نظرة على كل الحسابات
```

## البنية
```
CLAUDE.md                 دليل تشغيل الـ agent (العزل، مستويات القرار، القواعد)
.claude/skills/           الأوامر أعلاه
genx/                     الأدوات: دورة المنشور، القواعد، التقارير، الحزم
portfolio/config.json     إعدادات المحفظة (التعلم بين الحسابات مقفول)
accounts/<slug>/
  config.json             المنصات، الأفكار، الاستقلالية، الحدود، الكلمات الممنوعة
  brand.md ideas.md       الهوية والفكرتين
  character.md            دليل الشخصية (للشخصيات)
  playbook.md             ما تعلمناه
  plans/ posts/ media/    الخطط والمنشورات والميديا
  decisions.md            سجل قراراتك
```

## ما يفرضه الكود (قبل أي مراجعة)
خطة الأسبوع معتمدة، والفكرة من أفكار الحساب، والمنصات والصيغ مفعلة. وكمان: الكلمات الممنوعة، والحد اليومي، والفاصل الزمني، ومنع التكرار، ومنشور عميل واحد في الأسبوع مع إفصاح إعلاني، ووسم AI للشخصيات الواقعية.

## الأدوات مباشرة
```bash
python -m genx --help
python -m genx queue                 # كل ما ينتظر قرارك
python -m genx decide '*' all approve
python -m unittest discover -s tests -t .
```
Python 3.10+ بدون مكتبات خارجية.

## لسه ما اتبنى
- لوحة القيادة (الخطوة التالية).
- النشر الآلي وسحب الأرقام من المنصات: حاليًا الحزم يدوية والأرقام تُدخل، لحد ما نتحقق من شروط APIs المنصات أو نربط Windsor.ai.
- التشغيل المجدول (دورة أسبوعية وقياس يومي).
