# المراجعة

1. `python -m genx queue --json` (أو فلتر على الحساب لو اتحدد).
2. اعرض العناصر مجمّعة حسب الحساب. لكل منشور (من `show`):
   - الموعد، الفكرة (A/B)، الصيغة.
   - الخطاف والنص كاملين كما سيُنشرا، والهاشتاقات.
   - الفرضية، وملخص سطر لما سيُنتج (الصورة/الفيديو).
   اعرضها مرقمة عشان يرد بسهولة: «1 موافق، 2 غيّر الخطاف لـ...، 3 ارفض».
3. نفّذ:
   - موافق: `python -m genx decide <slug> <id> approve`
   - تعديل: `python -m genx decide <slug> <id> changes "<ملاحظته بالحرف>"`، ثم عدّل المنشور (`post-edit`) وأعد `submit`، واعرضه عليه مرة ثانية.
   - رفض: `python -m genx decide <slug> <id> reject "<السبب>"`
   - جماعي لحساب: `decide <slug> all approve` · لكل الحسابات: `decide '*' all approve`
4. لو رفض أو عدّل لسبب يتكرر (مثلًا «الخطافات طويلة»)، اقترح تضيفه لـ brand.md أو playbook.md.
5. في النهاية: كم اعتمد، وكم ينتظر إنتاج، واقترح `/produce`.
