# التقرير الأسبوعي

1. `python -m genx context <slug>` و`python -m genx list <slug> --status published`.
2. الأرقام الناقصة: اطلبها من صاحب الحساب (لقطة شاشة أو أرقام) وسجّلها:
   `python -m genx metrics <slug> <id> instagram reach=1200 likes=80 comments=6 shares=4 saves=15 follows=3`
   (لما يتربط Windsor.ai أو APIs المنصات، اسحبها من هناك بدل الطلب.)
   لقطة نمو الحساب (من إحصائيات كل منصة):
   `python -m genx snapshot <slug> instagram followers=340 profile_visits=120 reach=5200`
3. `python -m genx report <slug>` ثم حلّل:
   - أحسن وأسوأ منشور، ولماذا (الخطاف، الصيغة، الموعد، الموضوع).
   - A مقابل B على المؤشر الحاسم (`decisive_metric`).
   - أقل من 5 منشورات للمقارنة = فرضيات، ما نتائج. قلها بوضوح.
   - هل التجربة الأسبوعية أكدت أو نفت فرضيتها؟
   - السلاسل: أي سلسلة الناس متعلقة بيها؟
   - نمو الحساب: المتابعين وزيارات البروفايل (الأرقام تقول هل المحتوى بيجيب متابعين، ما مشاهدات بس).
   - المجتمع والدخل: استفسارات جديدة؟ دخل؟
4. اعرض على صاحب الحساب:
   - 3-5 أسطر خلاصة، بالأرقام.
   - التحديثات المقترحة لـ playbook.md (ما ينجح، ما يفشل، التجارب، أولويات الأسبوع القادم)، كل نقطة مربوطة بأرقام منشورات.
5. بعد موافقته: حدّث playbook.md، و`python -m genx portfolio`.
   - أول أسبوع في الشهر: حدّث البحث (`/research`) بمنشورات المنافسين الجديدة.
6. في الأسبوع 8: جهّز توصية القرار لكل حساب (نكمل، نعدّل، نوقف) بالأرقام.
